# 🧠 Number Quiz — Python

یک برنامه‌ی ساده‌ی **Quiz با پایتون** که از کاربر می‌پرسد عدد «fourteen» کدام گزینه است و پاسخ او را بررسی می‌کند.

## 📌 معرفی

در این پروژه کاربر باید از بین چهار گزینه، عدد درست را انتخاب کند:

* A) 14 ✅
* B) 4
* C) 40
* D) 44

اگر کاربر گزینه‌ی درست را انتخاب کند، پیام موفقیت نمایش داده می‌شود؛ در غیر این صورت پیام `Try again` نمایش داده خواهد شد.

## 🚀 نحوه اجرا

ابتدا مطمئن شوید **Python** روی سیستم شما نصب است.

سپس فایل پایتون را اجرا کنید:

```bash
python QuizMaster.py
```

در بعضی سیستم‌ها ممکن است لازم باشد از این دستور استفاده کنید:

```bash
python3 QuizMaster.py
```

## 🎮 نحوه استفاده

پس از اجرای برنامه، سوال زیر نمایش داده می‌شود:

```text
Which number is "fourteen" ?

A) 14
B) 4
C) 40
D) 44
:
```

حرف گزینه‌ی موردنظر خود را وارد کنید.

### پاسخ صحیح

```text
A
```

در صورت انتخاب پاسخ صحیح:

```text
🤩🤩 Perfect 🤩🤩
```

و در صورت انتخاب گزینه‌ی اشتباه:

```text
🧐🧐 Try again 🧐🧐
```
